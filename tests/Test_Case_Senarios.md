# 시나리오 상황·공문

## 1. B-01 냉동딸기 — 고정·변경 물량 분리 (기준 사례)

**상황**: 10월 16일, A사가 11월 1일부 냉동딸기 단가를 5,000원에서 5,500원/kg으로 올리겠다고 통보. 박 대리는 큐에서 W-20261016-001을 실행하고, 계약상 11월 1~10일분은 고정이라는 사실을 카드에서 바로 확인.

## 2. B-02 냉동 블루베리 — 박스 단가·월중 적용일·다중 견적

**상황**: 10월 27일, C무역이 칠레 작황 부진을 이유로 11월 16일부 단가를 박스당 120,000원에서 132,000원으로 올리겠다고 알림(A-01 메일). 박 대리는 박스 단가를 kg으로 바꾸고, 11월 6일 입고분이 적용일 전이라는 것까지 따져야 함. 견적은 다섯 건이 쌓여 있음.

**공문**

- 표 1행: 냉동 블루베리 / 칠레 / A등급 / 냉동(IQF) / 주문 단위 10kg 박스 / kg 환산 10kg / 기존 120,000원/박스 / 변경 132,000원/박스
- 하단 주석: “운송비 kg당 300원 귀사 부담(단가 별도), 기타 물류비 없음.”

## 3. B-03 깐마늘 — 인상 요청이지만 전 물량 고정

**상황**: F농산이 작황 부진으로 11월 1일부 깐마늘 단가를 8,000원에서 8,800원/kg으로 올려 달라고 함(A-02 메일). 박 대리는 “계약상 연말까지 고정 아닌가?”를 확인하고 싶음.

**공문**: “운송비는 기존과 같이 단가 포함, 별도 물류비 없음”
