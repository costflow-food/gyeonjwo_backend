## 업체와 주소 배정

| 역할 | 업체명 | 실제 테스트 주소 | 인증(합성) | 공급량 / 단가 / 조건 |
| --- | --- | --- | --- | --- |
| 기존 | 시연마늘농산 | 실행 담당자 배정 | HACCP | 1,000kg / 9,400→10,340원 / 배송 무료 |
| 대안 A | 시연대서유통 | 실행 담당자 배정 | HACCP | 1,000kg / 9,700원 / 배송 무료 |
| 제외 B | 시연미확인농산 | 없음 | 없음 | 필수 인증 FAIL로 제외. 회신·초안 없음 |
| 대안 C | 시연깐마늘식품 | 실행 담당자 배정 | HACCP | 1,000kg / 9,600원 / 운송비 추후 안내 → 70,000원/1회 |
| 대안 D | 시연알마늘 | 실행 담당자 배정 | HACCP | 최대 600kg / 9,500원 / 배송 무료 |

원산지는 모두 국산, 규격은 동일하다. HACCP는 **이번 합성 구매자가 정한 필수 조건**이며, 깐마늘 전체에 법적으로 필수라는 뜻이 아니다. 인증 실물 검증 사례로 사용하지 않는다.
거래 이력은 기존 1,000kg×9,400원, A 300kg×9,700원, D 200kg×9,500원, 각 2026-10-15의 합성 이력 3건이다. 과거 단가를 새 회신 견적으로 대신하지 않는다.

메일은 짧은 본문과 PDF로 구성한다. 단가·물량·세금·조건은 PDF에만 있다. 로컬 fixture의 `example.invalid` 주소는 실행용 주소가 아니다.
회사 정책은 허용 인상률 4%, 기존 업체 선호 폭 4%, 분산 허용, 최대 2곳으로 **실행 담당자가 설정·확인**한다. 정책이 없으면 임의로 4%를 채우지 않는다.
모든 견적에 MOQ 100kg, 발주 배수 20kg, 적용일 2026-11-15, 유효기한 2026-12-31, 납품 3일, 세금 면세를 적었다. 이는 계산을 통일하기 위한 테스트 가정이다.

## 공공 시세 표시

- 공급처: [aT 최근일자 도·소매가격 API](https://www.data.go.kr/data/15156063/openapi.do).
- 정확한 시리즈: `item_cd=258`, `vrty_cd=03`, `se_cd=02`, `grd_cd=04`.
- 사용자가 받은 2026-11-06 조사값: 179,200원/20kg = **8,960원/kg**, **중도매·상품**.
- 이 숫자는 저장된 응답을 재현한 참고값이다. 실서비스 실행 시 최신 공공 응답의 조사일·조회 시각을 따로 확인한다. 현재 날짜에 반드시 같은 가격이 나오는 테스트가 아니다.
- 예상 참고가격 차이(위 응답일에 한정): 기존 요청 +15.40%, A +8.26%, C +7.14%, D +6.03%.
- 거래 조건이 달라 단순 차이로 인상 적정성을 판정하지 않는다. 시세는 아래 구매안·역제안 산식에 들어가지 않는다.
- 시세 조회 실패·정확한 규격 미확인·7일 초과 시 해당 상태를 표시한다. 구매안 계산은 계속한다. 7일은 임시 MVP 기준이다.

## 손계산 기준선

| 안 | 식 | 총액 |
| --- | --- | ---: |
| 기존 유지 | 10,340×1,000 | 10,340,000원 |
| A 전환 | 9,700×1,000 | 9,700,000원 |
| C 전환 | 9,600×1,000+70,000 | 9,670,000원 |
| A400+D600 | 9,700×400+9,500×600 | **9,580,000원** |
| C400+D600 | 9,600×400+9,500×600+70,000 | 9,610,000원 |

③ 운송비 역전 기준: `9,700,000−9,600,000=100,000원`.
⑤ 유지 상한 단가(대안과 동일 총액): `9,580,000÷1,000=9,580원/kg`.
⑤ 정책상 역제안 상한: `min(9,400×1.04, 9,580×1.04)=9,776원/kg`.
9,776원은 최저 구매가격이 아니라 정책이 허용하는 상한이다. 실모델이 이 범위 내 다른 값을 고를 수 있으므로 정확히 9,776원만 정답으로 강제하지 않는다.
