# 이미 적용된 DB 설정 기록

`supabase/manual/20261019_reviewed_v18_to_v20.sql`은 운영 프로젝트의 빈 v1.8 suppliers를 전환할 때 사용한 1회용 SQL입니다. 새 DB 자동 초기화 스크립트가 아니며 이미 v2.0인 DB에 다시 실행하지 않습니다.

원래 업로드된 스키마 원본 문서는 복구되지 않았습니다. 이전 대화에서 확인한 정의를 검토·보완하여 적용했습니다. 원본 문서와 1:1 일치를 보증하는 자료는 아닙니다.

초안의 일일 ID 반복·여러 품목 중 조기 승인 문제를 보완했고, 기본 ACL·SECURITY DEFINER·서버 전용 권한을 검증했습니다. CSV 및 가상 seed는 포함하지 않았습니다.

이 백엔드의 실행/디버깅은 DDL을 실행하지 않습니다. DB 변경이 필요하면 별도의 검토와 마이그레이션으로 진행하세요. 저장소 반영만으로 이미 적용된 DB에 SQL이 다시 실행되지 않도록 자동 배포와 수동 기록을 구분했습니다.
