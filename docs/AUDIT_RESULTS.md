# 백엔드 재점검 결과

확인일: 2026-10-26. 이번 검토에서는 Python 전체 모듈, HTTP 경로, 상태 전이, 수신 워커, 원문 접근, 비용 계산과 자동 테스트를 대조했다. **발견한 아래 오류·누락을 수정했으며 자동 테스트 165개, 패키지 의존성 검사, Python 문법 검사가 통과했다.** 실제 외부 서비스 연동을 통과했다는 의미는 아니다.

## 검증 범위

- API 인증·접근 차단, 허용되지 않은 파일/참고자료 접근 차단, 비밀 토큰 열 필터링.
- 수신 영속 접수 후 응답, Gmail 전체 페이지·중복·커서 복구, 잘못된 OAuth 메일함 차단.
- 시작·완료·만료 토큰, 동일 업무 중복 및 단일 프로세스 동시 분석 차단.
- 정상 400kg 고정 + 600kg 변경 예시, 300,000원 증가액, 후보 비용 미확인 null.
- 누락·출처/단위 불일치·PDF 실패/총 4회·OCR 필요·비교 제외·계산 제안 오류·회차 불일치 시 처리.
- 새 비용 설명·RPC 응답·원문 본문·chunked JSON·응답 형식 오류에 대한 회귀 테스트.

## 아직 확인하지 못한 것과 범위 제한

1. **팀 Supabase 실제 접속:** 배포 SQL/RPC 반환 형식·GRANT/RLS·Auth app_members·버킷·private Broadcast를 실제 프로젝트에서 검증하지 않았다. 로컬 테스트는 대체 응답을 사용한다.
2. **Gmail/Google Cloud 실제 수신:** OAuth 동의/refresh token, Pub/Sub IAM·OIDC audience·구독·watch 알림·실제 메일 동기화를 계정으로 검증하지 않았다.
3. **LLM 실제 품질/호환성:** 노션의 모델 선택은 미확정이다. 팀 제공자가 JSON Schema/Chat Completions/store 옵션을 지원하는지, 원문 추출·독립 검증의 정확도·비용·지연을 검증해야 한다. 정확도 95% 달성을 주장하지 않는다.
4. **Flutter 통합:** 이번 작업은 백엔드다. 기존 Flutter 화면이 최신 queue_status·notes·동기 analyze·참고자료 API를 실제로 호출하도록 연결됐는지는 별도다.
5. **운영 범위:** 단일 프로세스·한 번에 한 건, 적용일 기준 월 전체 계획, 0.01원 HALF_UP을 사용한다. 다른 기간·반올림·동시성 정책은 팀 합의 후 코드·테스트를 함께 변경해야 한다.
6. **문서/확장:** 텍스트 PDF와 텍스트/HTML을 지원한다. 스캔 OCR·기타 문서는 검토 필요로 중단한다. MVP2 크롤링·외부 시세·초안·구매이력 반영, MVP3 발주는 범위 밖이다.
7. **네트워크 유실 후 원문 정리:** DB 등록 응답이 유실된 경우에는 이미 커밋됐을 수 있어 자동 파일 삭제를 하지 않는다. 그런 파일의 확인·정리는 DB 담당자의 운영 점검이 필요하다.

테스트 도구에서 Starlette/httpx 연동의 deprecation 경고 1개가 있다. 현재 테스트 실패는 아니며 기능 런타임 오류로 확인된 것은 아니다.

실연동 완료 여부는 위 1~4의 실제 계정·화면 검증까지 마친 뒤 판단해야 한다. 코드 점검만으로 ‘문제가 전혀 없다’고 보장하지 않는다.

## 추가 정확성 점검 (2026-10-26)

- 잘못된 천 단위 쉼표(예: `5,00,0원`)를 자동으로 제거해 숫자로 인정하던 동작을 차단했다.
- 박스 단가의 kg 환산에서 이미 kg로 명시한 요청 물량을 다시 박스 중량으로 곱하지 않도록 수정했다. 환산 불가능한 물량 단위와 중량 필드의 박스/개/금액 단위를 거부한다.
- 정상 완료 응답에서 물량 세 필드의 존재·유한성·음수 금지·합계·양수 총량, 확정된 기준 비용/변경 후 비용, 계산 상태와 비용 일치, 음수 단가 금지, 후보 거래처 중복, 기간 순서 및 정수 검증 회차를 확인한다.
- 전체 테스트 **165개 통과**. 그중 생성 검증 1개는 고정 시드로 금액·물량 조합 **1,000건**을 실행하며, 원 단가의 소수 둘째 자리와 kg 물량의 소수 셋째 자리 범위에서 정수 기반 HALF_UP 기준과 금액 합계를 대조한다. 이는 전체 가능한 입력 또는 실제 계정 연동의 무오류 보증은 아니다.
