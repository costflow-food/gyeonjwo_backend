## 코드 정답으로 사용할 세 사례

### AC-06: 낮은 단가가 낮은 총액은 아님

조건: 100개, 규격·인증·납기·공급량·가격 적용·세금 기준 동일, 다른 추가 비용 없음이 확인됨.

- A: 5,500원 × 100 + 무료 배송 0원 = **550,000원**.
- B: 5,400원 × 100 + 배송 20,000원 = **560,000원**.
- A가 **10,000원 낮음**. B가 60개만 공급 가능하면 B 전량 구매는 유효안이 아님.

### AC-09: 미확인 운송비의 역전 경계

- A 상품금액: 550,000원, 배송비 x 미확인.
- B 총액: 560,000원, 다른 조건 동일.
- A가 더 저렴한 조건: **x < 10,000원**. x=10,000원이면 동률, 초과면 B가 낮음.
- x를 0원·추정값·확률로 채우지 않는다. 질문할 값과 계산 경계를 제시한다.

### AC-10: 최대 공급량을 반영한 분산

조건: 1,000개, A5,500원·배송무료·잔여량 공급 가능, B5,400원·최대600개·배송10,000원, 분산 허용·MOQ/포장/세금/납기/추가 비용 조건 모두 확인됨.

- A 전량: 5,500 × 1,000 = **5,500,000원**.
- B 전량: **공급량 부족으로 INVALID**.
- B600 + A400: 5,400×600 + 5,500×400 + 10,000 = **5,450,000원**.
- A 전량 대비 **50,000원 낮음**. 분산 금지면 제외, B 공급량 미확인은 확인 우선순위로 반환.
